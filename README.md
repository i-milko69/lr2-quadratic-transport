# ЛР2. Транспортная задача с нелинейными потерями

## 1. Описание задачи

В данной лабораторной работе рассматривается транспортная задача с нелинейными потерями и квадратичной зависимостью стоимости перевозок от объёма груза.

Компания должна перевезти товары из (m) складов в (n) магазинов. Необходимо определить, сколько товара следует отправить по каждому маршруту, чтобы удовлетворить потребности магазинов, распределить запасы складов и минимизировать общие затраты на перевозку.

В отличие от классической транспортной задачи, где стоимость перевозки единицы товара по каждому маршруту постоянна, в рассматриваемой модели общая стоимость маршрута зависит от объёма перевозимого груза. Предполагается, что увеличение объёма перевозки приводит к росту затрат.

## 2. Обозначения и параметры модели

Введём следующие обозначения:

- (m) — количество складов;
- (n) — количество магазинов;
- (x\_{ij}) — объём товара, перевозимого со склада (i) в магазин (j);
- (a\_{ij}) — коэффициент базовой стоимости перевозки по маршруту (i \to j);
- (b\_{ij}) — коэффициент квадратичного роста стоимости перевозки;
- (s_i) — запас товара на складе (i);
- (d_j) — потребность магазина (j).

**Физический смысл коэффициентов**

Коэффициент (a\_{ij}) определяет базовую стоимость перевозки единицы товара по маршруту (i \to j). Он может отражать расстояние между складом и магазином, тариф перевозчика и другие факторы, определяющие первоначальные затраты.

Коэффициент (b\_{ij}) определяет интенсивность роста стоимости при увеличении объёма перевозки. Например, при высокой загрузке маршрута могут потребоваться дополнительные транспортные ресурсы, что приводит к увеличению затрат.

В модели коэффициенты (a\_{ij}) и (b\_{ij}) рассматриваются как заданные параметры. Их значения определяются при формировании исходных данных.

## 3. Функция стоимости перевозок

Стоимость перевозки (x\_{ij}) единиц товара по маршруту (i \to j) задаётся квадратичной функцией:

[\
c\_{ij}(x\_{ij}) =\
a\_{ij}x\_{ij}+\frac{1}{2}b\_{ij}x\_{ij}^{2}.\
]

Функция состоит из двух слагаемых:

- (a\_{ij}x\_{ij}) — базовые затраты, линейно зависящие от объёма перевозки;
- (\frac{1}{2}b\_{ij}x\_{ij}^{2}) — дополнительные затраты, которые увеличиваются квадратично при росте объёма перевозки.

Таким образом, при увеличении объёма перевозки стоимость растёт быстрее, чем в модели с постоянной стоимостью единицы товара, если (b\_{ij}>0).

Суммарная стоимость всех перевозок определяется как сумма стоимостей по всем маршрутам:

[\
f(x)=\
\sum\_{i=1}^{m}\sum\_{j=1}^{n}\
\left(\
a\_{ij}x\_{ij}+\
\frac{1}{2}b\_{ij}x\_{ij}^{2}\
\right).\
]

## 4. Математическая постановка задачи

Целью является минимизация суммарной стоимости перевозок:

[\
\min\_{x} f(x)\
]

при выполнении следующих ограничений.

### 4.1. Ограничения по запасам складов

[\
\sum\_{j=1}^{n}x\_{ij}=s_i,\
\qquad i=1,\ldots,m.\
]

Каждый склад отправляет весь имеющийся запас товара. Сумма объёмов перевозок со склада (i) должна равняться его запасу (s_i).

### 4.2. Ограничения по потребностям магазинов

[\
\sum\_{i=1}^{m}x\_{ij}=d_j,\
\qquad j=1,\ldots,n.\
]

Каждый магазин получает необходимое количество товара. Сумма объёмов поставок от всех складов в магазин (j) должна равняться его потребности (d_j).

### 4.3. Ограничение неотрицательности

[\
x\_{ij}\geq 0,\
\qquad i=1,\ldots,m,\quad j=1,\ldots,n.\
]

Объём перевозки не может быть отрицательным.

### 4.4. Условие баланса

Для существования допустимого решения в сбалансированной транспортной задаче необходимо, чтобы общий запас совпадал с общей потребностью:

[\
\sum\_{i=1}^{m}s_i=\
\sum\_{j=1}^{n}d_j.\
]

Это условие означает, что общего количества товара на складах достаточно для полного удовлетворения спроса всех магазинов без образования излишка или дефицита.

Итоговая модель имеет вид:

[\
\begin{aligned}\
\min\_{x}\quad&\
\sum\_{i=1}^{m}\sum\_{j=1}^{n}\
\left(\
a\_{ij}x\_{ij}+\
\frac{1}{2}b\_{ij}x\_{ij}^{2}\
\right)\\\
\text{при условиях}\quad&\
\sum\_{j=1}^{n}x\_{ij}=s_i,\
\quad i=1,\ldots,m,\\\
&\
\sum\_{i=1}^{m}x\_{ij}=d_j,\
\quad j=1,\ldots,n,\\\
&\
x\_{ij}\geq 0.\
\end{aligned}\
]

## 5. Обоснование выпуклости функции стоимости

Для анализа свойств функции стоимости рассмотрим её градиент и матрицу Гессе.

Частная производная функции по переменной (x\_{ij}) равна:

[\
\frac{\partial f}{\partial x\_{ij}}\
\=a\_{ij}+b\_{ij}x\_{ij}.\
]

Следовательно, градиент функции в векторной форме записывается как:

[\
\nabla f(x)=a+b\odot x,\
]

где (a), (b) и (x) — векторы коэффициентов и объёмов перевозок, а (\odot) обозначает поэлементное умножение.

Вторая производная по переменной (x\_{ij}) равна (b\_{ij}). Поскольку в целевой функции отсутствуют перекрёстные произведения различных переменных перевозок, матрица Гессе является диагональной:

[\
\nabla^2 f(x)=\operatorname{diag}(b).\
]

Если все коэффициенты (b\_{ij}\geq 0), матрица Гессе положительно полуопределена, поэтому функция стоимости выпуклая.

Если все коэффициенты (b\_{ij}>0), матрица Гессе положительно определена, поэтому функция стоимости строго выпуклая.

При сбалансированных исходных данных, неотрицательных запасах и потребностях, а также допустимых коэффициентах стоимости задача имеет допустимое решение. При (b\_{ij}>0) оптимальное решение по объёмам перевозок единственно.

Выпуклость важна для лабораторной работы, поскольку позволяет применять методы выпуклой оптимизации и обосновывает поиск глобального минимума, а не только локального.

Параметр штрафа обозначается через (\mu). Его выбор влияет на точность выполнения ограничений и обусловленность функции, которую оптимизирует алгоритм.

- невязка ограничений;
- разность между полученной стоимостью и эталонным значением;
- количество итераций;
- обусловленность задачи оптимизации.

## 7. Вывод

В работе рассматривается сбалансированная транспортная задача с квадратичной функцией стоимости перевозок. Квадратичное слагаемое позволяет учитывать рост затрат при увеличении объёма перевозки по одному маршруту.

Математическая модель включает ограничения по запасам складов, потребностям магазинов и неотрицательности объёмов перевозок. При неотрицательных коэффициентах квадратичной составляющей функция стоимости выпуклая, а при строго положительных коэффициентах — строго выпуклая.

Данная постановка служит основой для дальнейшего исследования градиентных методов, штрафных функций и способов улучшения качества оптимизации.
